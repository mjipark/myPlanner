# 민지's Planner

Study + daily planner for October 2026 exam season (VR assignment, 디지털회로 quiz, six midterms, ADsP 51회), with a daily rhythm that keeps going through November.

Two tabs (side rail on desktop, bottom bar on phones; swipe left/right on phones):

- **Plan** – the full exam plan, week by week. Each task shows a suggested length (~2h 30m) instead of a clock time, and each day shows its total study time and any 근로 hours
- **Calendar** – month grid; tap a day to see and tick its tasks

## Sync across devices

Ticks save to a private GitHub Gist (`myplanner-sync.json`) in your own account.

1. Tap the **Sync** pill → create a classic GitHub token with only the `gist` scope → paste → Connect.
2. Tap **Copy setup link** and open it on the other device (AirDrop / KakaoTalk to yourself). It stores the token there and removes it from the address bar.

The setup link contains your token, so only open it on your own devices. Sync runs on every tick, every 30 s while the page is open, and whenever you switch back to it.

## Install as an app

- Mac (Chrome): ⋮ → Cast, save, and share → Install page as app.
- iPhone (Safari): Share → Add to Home Screen.
